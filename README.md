# Bezpiecznik: paczki danych

Pliki pobierane przez aplikację Bezpiecznik po instalacji. Są w wydaniach (Releases), nie w repozytorium.

- `zachodniopomorskie.mbtiles`: mapa offline woj. zachodniopomorskiego (kafelki wektorowe, schemat OpenMapTiles, zbudowane Planetilerem z wyciągu Geofabrik).
